# UI、新闻与动效规范

## 视觉方向

平台默认浅色：钢蓝、米白、暖金和中性灰建立信息层级；避免全站重新变成暗色。3D 地球是独立的局部暗色舞台，可使用高辨识度的黄、橙、纯蓝等路线色，但不能让地球的局部主题泄漏到其他模块。

中文排版优先可读性和层级：短标题、明确单位、数据来源和截至日期同处一组；复杂内容用折叠、标签、选项卡或联动面板收纳，不把所有图表纵向平铺。数据缺失、fallback 和不适用必须通过文字和色标同时表达，不能只靠颜色。

## 晨报与潮汐早报

- 晨报以结论优先：将核心指标、价差、汇率/航运/钢材环比、行业快讯、风险与配额状态组合在有限的 1–1.5 屏信息结构中；删除无业务价值的占位句。
- 潮汐早报保留既有整体模板和 MySteel 数据接口，但新闻正文、来源、图片和“历史上的今天”必须按快照实际字段渲染。
- 新闻列表点击后进入沉浸阅读层，但正文区自身必须滚动：阅读层设定明确的 `overflow-y: auto`、`max-height`/视口布局，不能用 `preventDefault()` 或滚轮捕获阻断原生滚轮。
- 大图要使用真实关联图片、懒加载和明确比例；缺图显示事实状态。详情失败时保留摘要并标示详情未取到，不把摘要伪装成全文。
- 历史模块按人物/事件/年份组织；桌面支持 hover，触控设备使用点击固定展开且单开；悬停详情、图片和时间锚点必须来自历史数据，不可从普通新闻猜造。

## 地球与联动面板

地球路线采用“淡色底线 + 独立动态高亮线”两层结构，线路加粗、有区分色，并使用持续但低干扰的输送动画。起点可轻微散开减少遮挡，但终点和业务坐标必须准确。路线太多时优先筛选/分层，不以透明度堆叠掩盖信息。

出口国家交互应从路线移到排名卡：悬停/点击国家排名，地图对应线路加粗，右侧同步切换详情。右侧卡片按内部出口量占比降序，同时展示内部出口占各自总量比重和海关出口占各自总量比重；海关指标不必增加第二套地球线路。饼图国家顺序要一致，并配合文字/表格，不能只靠颜色辨识。

## GSAP 与响应式

- 只动画 `transform`、`opacity`、颜色等合适属性；避免在每帧读取并写入布局、避免大量 box-shadow/filter 导致卡顿。
- React 中用 `useGSAP` 或 `gsap.context()` 管理生命周期；路由切换、筛选变化、组件卸载时清理 timeline、listener 和 ECharts 实例。
- 默认过渡约 150–300ms；持续循环动效必须克制，并提供 `prefers-reduced-motion: reduce` 降级为静态状态。
- 悬停只在 `(hover: hover) and (pointer: fine)` 启用；`pointer: coarse` 用点击展开。所有按钮、关闭、展开、地图联动都要可键盘到达并有焦点反馈。
- 不要劫持页面滚动；不要制造横向滚动条；移动端在单列、图片比例和触控命中区上单独验收。

## 组件改动验收

视觉修改至少检查：信息层级、对比度、空状态、loading/fallback、窄屏、键盘和 reduced motion。动效修改至少检查：首次进入、重复进入、状态切换、快速切换、卸载后、触控降级和低动效模式；只看到静态截图不能算动效验收通过。
