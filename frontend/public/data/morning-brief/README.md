# 晨报本地语料与规则

这些文件是晨报的可配置表达层。它们只负责词条、语气和阈值说明，不承载任何业务事实。

- `keywords.json`：我的钢铁网快讯筛选词条与产品线映射。
- `rules.json`：结论、业务建议和风险提示的规则说明。
- `templates.json`：按事实类型组织的句式模板，变量必须由真实快照填充。
- `fragments.json`：可复用的短语片段。
- `thresholds.json`：需要人工复核的变化阈值；调整前应由业务负责人确认。
- `taxonomy.json`：产品、运输和合规术语的中文归类。

数据日期、数值、来源状态和 fallback 判断仍由 TypeScript 数据聚合逻辑负责，不能通过修改语料库制造结论。
