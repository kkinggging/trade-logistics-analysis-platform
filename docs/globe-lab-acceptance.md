# 3D 地球实验沙箱验收矩阵

## 隔离边界

- 原始入口 `#/globe` 的组件、样式、状态和 WebGL 实例不被实验模块复用或修改。
- 实验入口为 `#/globe-lab`，拥有独立的 `Globe` 实例、React 状态和 CSS 命名空间。
- 实验模块只读使用已有 JSON 快照；不写入数据、不改动抓取链路。
- 任意回滚以 Git 提交为节点：删除实验入口及 `features/globe-lab`、本验收文档即可恢复原功能。

### 国家匹配校验结果

- `world.json` 共加载 217 个国家/地区边界。
- 2025 内部业务快照共 77 条目的地记录，其中 75 条已与国家边界统一匹配。
- `中国台湾` 当前不在本版 `world.json` 的独立边界要素中；`欧盟` 是区域组织记录，不作为单一国家边界处理。
- 国家主键同时兼容业务中文名、海关 `label`、英文 `world` 和 GeoJSON 英文简称；例如“韩国 / Korea / South Korea”归为同一国家。

## 后续验收门槛

1. 业务国家悬停反馈时间不超过 100ms，且不重建 Globe 实例。
2. 连续选择 20 个国家时，选择状态、合计数值和地图高亮保持一致。
3. 客户合计按客户名称去重；全球占比和选择集合内占比必须分开标注。
4. 桌面端地球交互保持 50 FPS 以上；低性能设备降级持续动画，不影响选择功能。
5. 开启 `prefers-reduced-motion` 时，镜头切换立即完成，自动旋转与循环动效关闭。
6. 提供 2:1 等距圆柱投影高清底图后，只替换实验模块底图，国家交互层仍由 GeoJSON 独立渲染。

## 推荐实施序列

1. 国家边界交互层（本阶段）。
2. 单国家镜头聚焦与路线强调。
3. 多国家包围视角、集合比较图和救济/配额汇总。
4. 高清底图、云层和夜间纹理的可选叠加。
